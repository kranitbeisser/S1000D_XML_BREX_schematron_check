🚀 Analyst Workspace Guide

🔍 Filtering & Search

Use the Omni-Search at the top for quick text matches. Use the Tri-State Filters in the sidebar:

✓ Include only this value
✕ Explicitly exclude this value
Empty No filter applied

Click the Category Header (e.g. "Status") to expand or collapse the list.

📊 Data Table Tips

Sorting: Click any header name to sort (e.g., sort by RPC or Rule ID). Click again to toggle Asc/Desc.

Resizing: Drag the thin edge on the right of any header cell to resize columns.

Columns: Click the "Columns" button to show/hide fields. The order is fixed to S1000D standards.

📑 Analysis Page

Switch to the "Analysis Summary" tab to see visual charts of error distribution by Source and Rule ID. Charts update in real-time based on your current filters.

💾 Exporting

The CSV Export button generates a semicolon-delimited file containing exactly the columns currently visible in your table view.
